# 卡拉彼丘 UI 参考拆解（真实截图 → MC 模组改造）

来源：用户提供的真实游戏截图（选角 / 锁定 / 对局 HUD / TAB 计分板 / B 键成长 / 武器栏 / 技能栏 / 顶部面板 / 总体布局）。
用途：把真实 UI 的布局、信息层级、配色与交互映射到本模组的程序化 HUD（`client/hud/*`）与界面（`client/*Screen`）。

> 备注：用户按「第一张…第十张」描述，实际收到 9 张（缺第七张）。以下按收到顺序对应。

---

## 1. 选角界面（未锁定）

**真实布局**
- 顶部三段式进度条：`我方进攻`（红） | `选择角色` + 中央倒计时 `00:24` | `敌方防守`（蓝）；左上角地图名/模式（88区 / 爆破入侵）。
- 左侧竖列：5 名队友卡片（角色头像 + 名字），显示已选角色，未选为问号。
- 底部：**2 行 × 12 列 = 24 个超弦体头像网格**（当前选中者左上角 `P1` 标记，已锁定者绿色勾）。
- 中央：选角前为空白/场景；选中角色后（第 2 张）显示大幅立绘。
- 左下角：返回聊天提示键帽。

**我们的现状**：`StrinovaAgentSelectScreen` 是 6×4 卡片 + 右侧详情面板，没有顶部阶段条、队友列表、头像网格、锁定状态。
**差距**：布局需要重排；数据需要「本局队友列表 + 每人锁定状态」（当前 mock 可造）。

---

## 2. 选角界面（已选 / 锁定前）

**真实布局**
- 中央：角色大幅立绘 + 底部名字。
- 右侧信息面板（自上而下）：
  - 定位标签（如「决斗」）+ 3 个技能小图标（被动 / Q / E 或 C）；
  - 「Q 主动：技能名」+ 技能描述；
  - **武器选择面板**：主武器 / 副武器 / 近战武器 / 战术道具 ×2（当前值与切换按钮）；
  - 「武器选择 / 外观选择」两个页签；
  - 底部大按钮「**锁定角色**」。
- 底部仍保留 24 头像网格（选中者 P1，已锁定者绿勾）。

**我们的现状**：右侧详情只有定位描述 + 确定/随机/返回，无立绘、无技能/武器面板、无锁定流程、无阶段条。
**差距**：需要「技能占位卡片 + 武器面板 + 锁定按钮 + 阶段条」；立绘没有素材，先用程序化占位（色块 + 角色名/定位），后续换贴图。

## 3. 对局内总体 HUD（第 9/10 张）

**真实布局（按屏幕区域）**

| 区域 | 内容 |
|---|---|
| 顶部中央 | 左：我方 5 个角色头像（带绿色勾=存活/已锁定）；中：`目标9回合`、倒计时 `01:46`、双方比分 `00 / 00`；右：敌方 5 个头像；最外侧红/蓝斜切背景条 |
| 左上 | 地图名 + 模式（小字） |
| 右侧中部 | 目标点标记 `目标 A/B` + 距离（101 米 / 110 米），屏幕空间定位（世界坐标投影） |
| 右上 | 小地图（圆形/扇形雷达 + 目标图标） |
| 左下 | 角色头像 + 生命条（数值 130）+ 护甲条（数值 80，紫色/青色）+ 增益条（护甲恢复 / 静心凝势，绿色文字 + 图标） |
| 底部中央 | 技能栏：Q / X / C 三个菱形技能图标；X 显示绝招点数 `0/7`；未就绪灰显；下方小键帽 |
| 右下 | 武器栏：**竖排 1~5** 五个槽位（主武器/副武器/近战/战术道具 ×2），当前槽高亮 + 武器名 + 大号弹药 `20 / 205` |
| 中央 | 动态准星（十字 + 中心点） |

**我们的现状**
- 顶部：只有 `我方 3 : 2 对方 + 模式/回合/计时` 文本条（无头像、无目标回合、无比分方块）。
- 左下：生命/护甲双条 + 文字标签（无头像、无增益图标、无紫甲色）。
- 底部中央：Q / E / X 三个方块 + 终极条（真实是 Q / X / C + 菱形 + 绝招点数）。
- 右下：横向 4 槽 + 大数字弹匣（真实是竖排 5 槽 + 武器名 + 弹药大数字）。
- 无小地图/目标点距离（需要世界坐标投影与地图系统，暂缓）。

**差距（P0 改造项）**
1. 顶部比分面板重做：双方头像行 + 中央「目标回合 / 倒计时 / 比分」。
2. 左下血甲重做：头像 + 数值 + 紫/青配色 + 增益提示。
3. 底部技能栏重做：Q / X / C 菱形 + 绝招点数。
4. 右下武器栏重做：竖排 1~5 + 当前武器名 + 弹药。
5. 小地图与目标点距离：P2（依赖模式/地图系统）。

## 4. TAB 计分板

**真实布局**
- 左右两块队伍面板：队伍名（剪刀手 / 欧泊）+ 大徽章 + 比分（0）。
- 表头列：`击败/阵亡/助攻` | `绝招` | `成长等级` | `主武器` | `输出分` | `技能分` | `协作分` | `PING`。
- 每行：角色头像 + 名字 + 三项数据 + 绝招点数 + 成长等级（蓝/金色块）+ 武器图标 + 三项分数 + PING；存活者绿色勾。

**我们的现状**：只有「超弦体 + K/D/A + 状态 + 血甲条」，无成长等级、武器图标、输出/技能/协作分、PING、队伍徽章。
**差距（P1）**：扩列 + 队伍头 + 分数列（先 mock 0）；头像/徽章用程序化色块占位。

## 5. B 键「弦能增幅网络」（成长/加点界面）

**真实布局**
- 顶部：标题「弦能增幅网络·角色名」+ 中央「拥有能量点：330」+ 右侧「准备阶段 00:25」+ 关闭按钮。
- 左侧：角色立绘 + 名字 + 定位。
- 中间两列成长类别（每项两个升级项，带 150/250 能量点价格）：
  `输出`（基础伤害提升 / 五连发射击模式）、`暴击`（爆头伤害提升 / 弦化伤害提升）、`续航`（载弹数量提升 / 换弹速度提升）、`精准`（散射控制提升 / 后坐控制提升）、`咒法`（冷却减少 / 伤害提升）、`护甲`（轻型护甲 / 重型护甲）、`弦化`（移速 +15% / 减伤系数 46%）。
- 右侧武器栏：1 主武器 / 2 副武器 / 3 近战 / 4~5 战术道具。
- 底部觉醒 1/2/3：图标 + 名称 + 描述 + 激活状态。

**我们的现状**：无此界面。
**差距（P2/P3）**：新增 `StrinovaGrowthScreen`（成长/加点），数据先 mock；与选角界面共享角色数据。

## 6. 武器栏（第 6 张特写）

竖排槽位，从上到下 5→1：战术道具 5、战术道具 4、近战 3、副武器 2、主武器 1（当前高亮）；主武器行显示武器名「枫鸣」+ 弹匣/备弹大数字 `20 / 205`；每个槽右侧数字键帽。
**映射**：`StrinovaAmmoWidget` 需要从横向 4 格改为竖排 5 格 + 武器名 + 大字弹药。

## 7. 底部技能栏（第 8 张特写）

Q / X / C 三个菱形（旋转 45° 的方框），Q 下方黄色小进度条，X 中央 `0/7` 绝招点数，C 灰色未解锁；图标中心为技能符号，未就绪时变暗。
**映射**：`StrinovaSkillsWidget` 改为菱形三格 + 点数；当前 Q/E/X 语义与真实 Q/X/C 对应关系待定（等技能系统）。

## 8. 顶部面板（第 9 张特写）

左右各 5 个角色头像（带绿色勾），中央上下两行：`目标9回合` + `01:46`，下方红 `00` / 蓝 `00` 分数；两端红/蓝斜切装饰条。
**映射**：`StrinovaMatchHeaderWidget` 重做：头像行（占位色块+角色名首字）+ 中央回合/计时/比分。

## 9. 改造优先级建议

| 优先级 | 内容 | 涉及文件 |
|---|---|---|
| **P0** | 对局内 HUD 对齐：顶部面板、左下血甲、底部技能栏、右下武器栏 | `StrinovaMatchHeaderWidget`、`StrinovaVitalsWidget`、`StrinovaSkillsWidget`、`StrinovaAmmoWidget`、`StrinovaHudState`（新增字段）、mock |
| **P1** | TAB 计分板扩列：成长等级/绝招/武器/输出/技能/协作/PING + 队伍徽章 | `StrinovaScoreboardState`、`StrinovaScoreboardOverlay`、lang |
| **P2** | 选角界面按真实布局重排：顶部阶段条、左侧队友列表、底部 2×12 头像网格、中央立绘占位、右侧技能/武器面板、锁定按钮 | `StrinovaAgentSelectScreen`、`StrinovaAgentRoster`、mock |
| **P3** | B 键「弦能增幅网络」成长/加点界面 | 新 `StrinovaGrowthScreen` + 成长数据契约 + lang |

**素材策略**：继续走 A 路线（程序化绘制）：头像=角色名首字/色块，立绘=渐变占位，武器图标=几何图形；贴图接入时只替换 Painter / 图标提供者，布局与数据不变。
